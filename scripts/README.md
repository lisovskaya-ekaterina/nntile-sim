# Вспомогательные скрипты NNTile Simulator

В этой папке находятся инструменты для анализа трасс NNTile, проведения сравнительных экспериментов и проверки глобального планировщика.

Основной код симулятора и алгоритма планирования находится в `src/nntile_sim/`.

## 1. `analyze_handle_sizes.py`

**Назначение:** анализ размеров хэндлов в трассах NNTile.

Используется для исследования распределения размеров данных и оценки эффективности их разбиения на чанки.

В дальнейшем результаты анализа могут помочь при разработке алгоритма выбора размеров чанков.

## 2. `benchmark_nntile_graph.py`

**Назначение:** сравнительное тестирование алгоритмов управления памятью GPU на трассах NNTile.

Сравнивает три политики:

- `lru-demand` — загрузка по требованию с вытеснением LRU.
- `belady-demand` — загрузка по требованию с вытеснением по Белади.
- `global-planner` — глобальное планирование загрузок, выгрузок и вычислений.

Для каждой конфигурации рассчитываются время выполнения (`makespan`), ускорение относительно LRU, занятость вычислительной линии, объёмы передач H2D/D2H и пиковое потребление памяти.

**Пример запуска из корня репозитория:**

```bash
PYTHONPATH=src python scripts/benchmark_nntile_graph.py \
  examples/tasks_mbs1.rec \
  --capacities-mib 768 1024 1536 \
  --h2d-gbps 12 \
  --d2h-gbps 12 \
  --chunk-mib 1 \
  --output results/global_comparison/benchmark.csv
```

Результаты сохраняются в CSV. Дополнительно формируется файл событий с суффиксом `_events.csv`.

## 3. `validate_global_planner.py`

**Назначение:** проверка корректности работы глобального планировщика.

Используется для проверки построенного расписания и выявления нарушений ограничений модели.

Проверка корректности необходима перед сравнением производительности алгоритмов и после изменений планировщика.

## Общие правила

- Все скрипты запускаются из корня репозитория.
- Результаты экспериментов сохраняются в `results/`.
- Скрипты не содержат основную реализацию алгоритма.
- После изменения алгоритма необходимо запускать тесты:

```bash
PYTHONPATH=src python -m pytest -q
```

Подробное описание алгоритма находится в `ALGORITHM.md` в корне репозитория.
